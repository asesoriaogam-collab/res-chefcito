## Créditos e Inspiración

Este proyecto es una obra derivada y se ha desarrollado tomando como base e inspiración el trabajo de los siguientes repositorios de código abierto:

* **[Curse_Rat v3.0.0](https://github.com/thorthehacker/Curse_Rat)** - Desarrollado por [@thorthehacker](https://github.com/thorthehacker). Se utilizó como modelo principal para la estructura de directorios (`client`, `server`, `assets`) y la arquitectura base del proyecto.
* **[D-L3MON](https://github.com/rootuserdj/D-L3MON)** - Desarrollado por [@rootuserdj](https://github.com/rootuserdj) (basado en el trabajo original de Dhananjay Sah). Se tomaron referencias de su lógica de control y características de administración remota para complementar las funciones de este repositorio.

Agradecemos a los autores originales por compartir su conocimiento con la comunidad de investigación de seguridad y desarrollo.
